# 安卓「分数记录」· dot 开发交接包
版本：1.0 · 2026-10-17（Asia/Seoul；当前这轮用户消息为 2026-10-16 UTC）

这是给 ChatGPT dot 的**开发工作包**，不是已完成、已签名或已经上架的 App。
正式功能范围由 `docs/PRD.md` 决定；当前实现和测试状态见 `docs/IMPLEMENTATION_STATUS.md`。

## 你只需要做什么
把完整 ZIP 上传到 dot 同一个项目对话，把 `DOT_START_PROMPT.txt` 全文发送给它。
不必逐个上传文档，不必自己挑框架。让 dot 解压到持久工作目录，再从 `START_HERE.md` 开始。
`AGENTS.md` 是项目约定，启动提示会要求显式读取；不假定 dot 会自动发现所有文件。

如果 dot 的当前工具只能阅读 ZIP 文件卡、不能取得文件字节，使用配套的 `DOT_ALL_IN_ONE.md` 阅读需求；
源代码仍须让它通过实际可用的文件工具取得，不能把“看到了文件名”当成已解压。

## 已经替你决定
- 安卓原生 Kotlin + Jetpack Compose + Room；不使用网页套壳，不做 Flutter/iOS 双端首发。
- 面向家长，中文优先；本地记分、趋势、PDF、备份恢复；不做云同步、OCR、AI 诊断、题库、社区。
- 免费体验 + 一次性解锁的产品规则；人民币 ¥18 是建议价格，不是已配置商品。
- 先做不依赖 Google 服务的 `localBetaDebug` APK；内测全功能，不收钱，界面明确标识内测。
- 正式 Play/国内渠道支付另设门禁，不用“点击即购买成功”的假实现交付商业版。
- 默认只在工作目录开发；没有指定本项目 GitHub 仓库，不得写入此前交易或客服助手仓库。

## 文件地图
`docs/`：PRD、UI、架构、数据与统计、导出、隐私、支付、发行和验收。
`tasks/`：带依赖的任务、验收用例、决策、交接、待办与证据状态。
`core/`：可独立运行的 Kotlin 业务规则与契约测试。
`app/`：Compose + Room 安卓起步工程；不是全功能 App。
`contracts/`、`fixtures/`、`reference/`：备份格式、虚构样本、独立校验器和测试。
`tools/`、`.github/workflows/`：环境检查、Gradle 引导、CI、产物校验与发布阻断。
`release/`：用户必须掌握的签名、渠道、支持邮箱等非秘密配置模板。
`evidence/`：本次真正执行过的检查；未执行项如实标注。

## 最重要的交付要求
让 dot 给出**真实可安装的 APK + 对应源码 + 构建日志 + 测试证据**，而不是仅声称“已完成”。
手机实测、购买沙盒、商店审核和商业发布必须分别有证据。任何一项未做，都不可用另一项替代。

# 证据目录
本包制作过程的记录以 `kit_` 开头，与未来 dot 开发产品的证据分开。
`validation_summary.json` 记录本包实际执行状态；没有列为PASS的层级不得推定已通过。
推荐后续每项证据：时间、代码commit/包哈希、环境、准确命令、退出码、原始日志、截图/录屏、用例ID。
失败和未执行都要保留。截图只用虚构成绩，不上传真实孩子信息。
商业门禁证据JSON结构示例：
```
{"status":"NOT_RUN","verifiedAt":null,"checkedBy":null,"artifacts":[]}
```
只有真实完成对应检查后才填写PASS，不用本例代替渠道购买或法律意见。

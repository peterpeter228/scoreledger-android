# 风险登记
| 风险 | 等级 | 触发信号 | 处理/门禁 |
|---|---|---|---|
| dot没有SDK/虚拟化 | 高 | 预检缺失/模拟器不可运行 | 可用环境安装或已授权CI；真机单独待测 |
| 依赖无法下载 | 高 | 超时/403/仓库阻断 | 记录具体错误；批准网络后重试，不降低安全性 |
| 成绩因迁移/恢复丢失 | 致命 | 任一回滚/升级case失败 | 阻断发布，修复+迁移测试 |
| 统计误导 | 高 | 用得分率冒充标准分 | 共享core+规则测试+口径警示 |
| PDF乱码/截断 | 高 | 中文、多页/分享失败 | 真机+阅读器逐页检查；不缩字掩盖 |
| 国内支付/资质未明确 | 高 | 无商店账户/商品 | 仅交内测，商业版阻断 |
| 纯客户端购买可被篡改 | 中高 | 轻易伪造权益 | 明确风险；批准后轻量验单，不上传成绩 |
| 系统/厂商自动迁移 | 中高 | 关闭备份仍被复制 | 配置排除+实测+真实隐私表述 |
| 免费需求但无人付费 | 高商业 | 只下载不复用 | 真实用户验证，不迷信iOS榜单 |
| 名称/素材侵权 | 中高 | 与竞品视觉相似 | 原创+发布前权利核查 |
| 签名密钥丢失 | 致命运营 | 只存云临时目录 | 用户持有备份，正式签名门禁 |
| 并行代理冲突 | 中 | schema/UI同文件多人改 | 单写者+接口先行+分支审查 |

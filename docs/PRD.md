# 产品需求文档 PRD｜安卓「分数记录」
版本 1.0 · 2026-10-17 · 状态：需求基线，等待 dot 实施

## 0. 产品决策摘要
面向使用安卓手机的家长，把散落的孩子考试成绩整理为可查看、可对比、可带走的私人记录。
核心承诺：**少操作地记下事实，清楚展示变化，数据始终由用户掌握。**
不是学习诊断、提分预测、校务系统或面向全校的排名服务。
工作名“分数记录”，内部代号 ScoreLedger；不是模仿现有“分数本”的品牌或美术。
正式名称、应用 ID 和商标风险在首次外部分发前核实；当前 `com.example.scoreledger` 为开发占位。

## 1. 目标用户与任务
首要用户：需要整理一名或多名孩子考试成绩的成年家长；孩子不是购买和营销的直接对象。
场景 A：收到考试成绩，用一个页面录入各科；不同科目满分可以不同。
场景 B：下一次考试后，查看某一科的原始分数、满分及得分率变化。
场景 C：家长会前导出一份带数据范围和口径说明的 A4 报告。
场景 D：换手机或重装前，导出备份，并在新安装中验证恢复。
不要求学校、班级、生日、真实姓名、电话号码、学号；昵称与年级文本足够。

## 2. 成功标准（内部目标，不是现成事实）
技术：P0 用例全部通过；没有已知导致数据丢失/串孩子/统计错误的问题。
体验：5 位目标家长独立完成首次录入、查看趋势和备份；观察卡点，而非只问是否喜欢。
商业：正式支付上线后获得 10 位非熟人付费用户，核查真实交易；内测用户不算收入。
时间：为三个月内完成产品与初始商业验证服务，不保证审核或账户申请的处理时间。
性能：指定 4 GB RAM 中档安卓参考机上，500 次考试/5,000 条成绩列表不明显卡顿；
已安装冷启动到可用目标 <2 秒、保存目标 <500ms、10页以内报告目标 <5秒；均待实测，不宣称已达到。

## 3. 平台和发行范围
最低支持 Android 8.0/API 26；compileSdk/targetSdk 36 为当前工程基线。
Google Play 当前对新应用的 API 要求见 [S08]；提审前重查，不通过降低 target 回避问题。
中文（简体）首发，界面字符串集中管理，为未来英文预留，不做首版多语言推广。
本地内测版本不依赖 GMS，验证普通安卓设备和用户实际手机；不承诺不兼容 Android APK 的其他系统。
手机优先，平板用自适应宽度；不固定方向、不禁止字体放大，不申请忽略电池优化。

不能以“增强转化”为理由加入焦虑式文案、红色差生标签或强制分享。

## 6. 数据模型简述
Child：UUID、昵称、年级文本、归档标志、创建/更新时间。
Subject：UUID、名称、默认满分（只是下次输入建议）、排序、归档标志。
Exam：UUID、childId、标题、ISO本地日期、考试类型、学期、年级快照、备注、创建/更新时间。
Score：examId+subjectId 唯一；科目名快照、满分、状态、可空分数。
Draft：独立 JSON 草稿及更新时间，不算正式考试，不进入统计和付费计数。
所有成绩以整数“百分之一分”存储，例如 87.5→8750。具体见数据契约。
初版最多20个孩子、100个科目、10,000次考试、每次30科、100,000条成绩；超限友好提示，非无限扩容承诺。

## 7. 录入规则
- 得分允许0，最多2位小数；满分 >0 且 ≤10,000；得分≤满分。首版不支持加分超满分。
- 输入支持全角数字规范化；明确拒绝负号、科学计数、千位逗号和超过2位小数，不静默改写。
- 状态：SCORED有分数 / ABSENT缺考 / MISSING未录入。后两种 scoreMinor 必须为空，不存0。
- “没有参加的科目”可不加入这次考试；已添加的缺考科目保持缺考状态。
- 至少选择1科；允许所有科目均为缺考/未录入，这仍是一次记录，但不生成得分率。
- 日期默认设备当天，可改为过去日期；未来日期在正式保存时拒绝，计划考试不在范围内。
- 同日多次考试合法；相同名称/日期可提示重复但不武断阻止，UUID做真正幂等键。
- 标题1–60字符；昵称1–24；学期0–40；年级0–30；备注≤500；科目名1–30。
- 编辑不改变原考试ID；新增新UUID；保存按钮处理中禁用，失败保留草稿并显示可操作错误。
- 软键盘下一项跳到下科；满分默认值源于科目设置，但这次成绩有独立快照。

## 8. 查看与统计
默认首页显示当前孩子、最近考试和“记一次成绩”。不混入其他孩子数据。
单科趋势默认得分率，点按显示日期、考试名、得分/满分、状态；另有可访问的等价表格。
缺失点为断点，不跨越缺考自动平滑连线；相同日期以考试顺序定位并明确标出标签。
不对曲线做平滑/插值，不把小范围自动缩放造成的波动放大；得分率轴默认0–100。
总得分率是有成绩科目的 sum(score)/sum(max)，不是各科百分数简单平均。
“同比变化”不作为默认词；只展示两次记录间的客观变化，并提示难度/范围不可等同。
可比总分要求同孩子、同年级快照/学期/类型、相同科目集合与满分且都完整；不满足就不显示总分进退步箭头。
详细规则及示例以 `STATISTICS_RULES.md` 为准，UI/PDF/测试调用同一 core。

## 9. PDF
免费：已有数据的基础明细报告，含完整分数/满分/状态和必要分页，永久免费导出。
专业版：趋势+摘要+明细+家长手写备注留白的完整报告；内测可测试完整模板。
“尽量一页”的是摘要，数据多时必须分页，不能截断或靠缩到看不清实现一页。
默认匿名昵称；导出前展示含孩子信息的提醒，可选择隐藏昵称和备注。
日期区间、筛选条件、生成时间、缺失数量、统计口径必须可见；文件名不含孩子名。
无需读取相册或全盘权限；用系统选择器保存，系统分享面板分享。见 PDF 专项规范。

## 10. 备份与恢复
备份独立于 PDF；PDF 不能当作可恢复备份。
导出 UTF-8 JSON v1 明文文件，导出前提醒保管，用户选择本地/其他文件提供方；不称加密。
首版只做**完整替换恢复**，不做不确定的自动合并。导入前显示孩子/考试/成绩计数和日期范围。
先通过结构、大小、ID、引用、值域与版本验证；用户二次确认后，单一Room事务替换。
替换前创建内部回滚快照；失败保留原数据；内部快照不等于手机丢失后的备份。
新版本/损坏/超限文件拒绝且不改库。导入任意有效记录不被收费阻止。
备份不得携带购买状态、设备标识、令牌、密钥、系统路径、草稿或任意代码。
卸载通常删除本地数据，必须在设置显著说明。系统自动备份与厂商换机不能当作唯一恢复保障 [S07]。

## 11. 收费规则（实现不得含糊）
免费状态：最多保留3次正式考试，最多1名未归档孩子；这3次按全库而非每个孩子/每科计算。
删除一次考试后释放名额：这是刻意保留的轻用户路径，不实现累积追踪或反作弊设备标识。
未填完但保存为正式考试也计1次；草稿不计；编辑已有考试不计新增。
专业版一次性解锁多记录、多孩子及完整报告；建议¥18，实际价格由发行渠道返回的本地化商品信息决定。
没有月费/年费；不承诺免费提供未来新产品或云服务。
恢复较大备份/退款/换渠道后：已有数据可看、可编辑纠错、可删除、可基础导出、可备份恢复；只限制新增和付费模板。
收费入口说明具体权益和恢复购买路径，不在首次启动立即遮挡。
localBeta是明确标识的免费内测全功能状态，不是已购买、也不写入可导出的“永久VIP”。
Play和国内渠道隔离：正式渠道尚无主体/配置/授权时只交内测，商业发布保持阻断。

## 12. 隐私、安全与权限
本地功能不联网、不用广告分析SDK、不上传任何孩子信息；正式支付SDK的数据处理单独披露。
应用目标为家长并不等于可以忽略儿童数据保护；相关适用性见 [S15]，发行前核实。
禁用自动云备份，配置云与设备迁移排除规则；仍对厂商换机差异实测，不保证防止所有系统级复制 [S07]。
仅使用内部沙盒和用户选择的文档URI；临时PDF在专用cache/reports内，定期清理；不把日志当数据备份。
不要求长时间后台服务、开机启动、通讯录/位置/相机/麦克风/通知/全盘权限。

## 13. 非功能验收

显示：320dp窄屏、2倍字号、深色、横竖屏、系统返回与输入法；检查Android新target的边到边布局。
兼容：模拟器API26和36；至少一台有GMS、一台无GMS安卓真机；用户实际手机优先且型号待确认。

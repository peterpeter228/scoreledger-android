# 备份/恢复规格与威胁模型

## 导出
用户点击设置→备份→读取明文提醒→系统CreateDocument(application/json)→一致快照→内部临时生成→写目标URI。
默认文件名 `scoreledger-backup-YYYYMMDD-HHmm.json`，不含昵称。
成功以目标输出流写入并关闭无异常为准；可重开时进行格式核查。仅此后更新lastSuccessfulBackupAt。
部分文档提供方可能生成不完整文件：失败需明确告诉用户未完成并建议删除失败文件，不覆盖内部原数据。
SAF由用户选择URI，不需要全盘权限 [S06]。用户选第三方云盘是其主动导出，不等于App自动上传。

## 导入
最多96MiB（100,663,296字节；ADR-2026-10-17-Backup）；以限长流读取，不信文件扩展名和提供方声明长度。拒绝ZIP/加密压缩包/路径引用。
步骤：读取→严格JSON→结构/语义验证→保留原值的不可变对象→显示预览→用户确认→内部回滚快照→单事务替换。
恢复界面显示当前数据数量与即将替换数量；默认取消。写入期间禁止并发新增/编辑。
任何异常（解析、失去URI权限、存储满、DB失败、进程退出）都不得先清空数据库。
Room事务保证替换的原子性；导入事务提交后不得因UI重试再执行一次删除。
替换前内部快照创建失败则停止，用户先导出可带走备份。快照留存最近3份或7天，主动清理操作须提示。

## 内部快照
存noBackupFilesDir，原生系统备份排除；不是多副本灾备，不保证卸载或丢手机后恢复。
只记录数据不记录权益。未经用户操作不上传给开发者；日志只记录计数与错误码。
未来加密备份使用独立版本和成熟AEAD库，不能把CRC/SHA-256叫加密。

## 跨设备和跨渠道
备份可迁移业务数据，不能迁移购买。恢复5个孩子100次考试即使免费也接受，但新增按权益门禁。
只做替换；合并/重复冲突解决P1另议。重复恢复同一文件应得到等价数据，不翻倍。

## 必测
往返等价、未知版本、重复JSON键、孤儿FK、重复score、伪bool整数、NaN、超限、损坏UTF8、取消、空间不足、
事务中断、重复恢复、多孩子隔离、支付字段注入拒绝、恢复后统计一致、卸载警示、国产文件管理器URI。

实现细节：Gson2.14.0严格流式解析、最大嵌套3、单次解析操作16KiB字符预算（含最多1024字符预读），过量空白填充也拒绝。UTF8损坏、负零、未配对代理字符拒绝；未来有效日期仅恢复允许。回滚JSON不含草稿；恢复失败保留原草稿，成功则按预览确认丢弃。预览后任何记录或草稿变化要求重新选择确认。内部快照不是可携带备份。

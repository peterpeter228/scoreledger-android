# 分数记录 0.2.0-beta 内测交付

## 安装
- Android 8.0 或更新系统，离线使用，不依赖 Google 服务。
- 已安装旧版时，建议先导出 JSON 备份并妥善保存，再直接安装覆盖更新。不要先卸载；卸载通常会删除本机数据。PDF 不能恢复数据。
- 本包沿用固定内测签名，版本号 2，包名 com.example.scoreledger.beta.debug。不要安装源码包中的 androidTest APK，它仅供自动验收。
- 这是免费内测版，不是已开通支付或正式上架版本。

## 本轮改善
- 录入主流程、草稿保存反馈、保存后详情、多孩子隔离、历史搜索和返回状态。
- 成绩的零分、缺考、未录入严格区分；年级和科目保留历史快照，写入具有事务和并发冲突保护。
- 绿色深浅色界面、固定保存入口、紧凑科目行、窄屏与大字体键盘避让。
- 趋势固定 0–100 得分率坐标，缺考处断开，提供原值明细；不输出 AI 诊断。
- 完整 PDF、本机预览、分段报告、真实系统文件选择器保存和取消重试。
- JSON 备份恢复、完整替换前预览、回滚副本和恢复失败保护。
- 修复成功提示遮挡操作、无编辑器时误报关闭、旧界面回调覆盖较新输入等问题。

# 把开发包交给 dot
推荐：在用于本项目的 dot 对话中上传完整 ZIP，然后发送 `DOT_START_PROMPT.txt` 全文。
文件较小，不含 Android SDK、Gradle缓存或模型权重；依赖在 dot 自己的可用构建环境取得。
不要把压缩包里的所有内容贴进同一条对话；入口会指导它按任务分批读取。

正式开始前，dot应报告解压目录、文件完整性和环境检查结果；不要把“看到附件”当成“工程已建立”。
`python3 tools/verify_checksums.py` 验证未修改初始包；源码修改后哈希变化是正常的，另记commit。
本包不是插件安装文件；`AGENTS.md`必须显式读，`PROJECT_STATE.json`不是OpenAI专属配置API。

如果当前文件工具不能取得ZIP字节，单独上传 `DOT_ALL_IN_ONE.md` 可让它先读产品需求。
合并阅读版不包含全部源代码字节，不能因此声称已取得工程；源代码仍需通过实际可用文件能力获取。
断点续接用 `DOT_RESUME_PROMPT.txt`，并要求核对工作目录及最近证据而不是从聊天回忆重造项目。

本轮无需预先提供：真实孩子数据、银行卡、PAT、签名密码或其他项目的账号密钥。
进入正式发布前才集中处理应用ID、主体、隐私网址、渠道商品和签名保管，禁止从旧项目擅自套用。

# 统计规则：全项目唯一口径

## 存储与格式
`scoreMinor/maxMinor` 为 Long，1=0.01分。100分=10000，87.5分=8750。
原始输入最多两位小数，存储不舍入；计算使用BigDecimal，百分率显示2位、HALF_UP。
不能用Float/Double保存原分数；图表渲染最终坐标才转浮点。

## 得分率
仅SCORED有得分率；`rate = scoreMinor *100 / maxMinor`。
0分为有效0%；缺考/未录入的rate=null，不参与分子和分母。
例：语文80/100，数学90/150：汇总=170/250=68.00%，不是(80%+60%)/2=70%。
若另有英语缺考/100：仍是已录科目68%，但覆盖为2/3，必须标“不完整”；不能显示“总分170/350”。
无SCORED结果：得分率为null、显示“暂无可计算成绩”，不是0%。
不生成百分位、标准分、IQ、学习能力评级、未来成绩预测。

## 变化
同一科目80/100到90/120：80.00%→75.00%，得分率变化-5.00个百分点，原始分数+10分。
两者可以同时展示，不能只显示“提高10分”来暗示能力提升。
精确差值计算后再舍入，不从两个已舍入的显示值相减。
变化描述用“较所选上次记录”，不是难度相同的因果结论。

## 汇总比较门禁
两次考试必须：同孩子、相同学期/年级快照/考试类型，均所有选中科目SCORED，
相同subjectId集合，各科maxMinor完全相同。否则返回不可比较及原因，不输出总分上升/下降箭头。
相同subject名字而ID不同不自动合并；改名字不改ID，历史快照保留。
“可比”只指数据口径一致，不证明试卷难度一致；仍有免责声明。

## 趋势序列
按examDate升序、createdAt升序、id稳定排序；输入顺序不影响结果。
只展示用户选择孩子/科目；不跨孩子。不同学期/年级可分段，不自动推断连续能力。
缺考/未录入所在考试应展示标记或列表行，并断开曲线；不要跳过后连成完整连续线。
默认0–100固定纵轴，无插值、无预测线。日期相同的点采用顺序轴并保留日期/考试名称。
每个图必须有文字/表格替代，不能只靠颜色。

## 手工排名 P1
rank≥1，population≥rank；population缺失可只显示名次，不计算百分位。
排名改善 = 旧名次 - 新名次，但只有相同明确群体才可提示；首版不自动比较群体。

# UI/UX 设计规范

## 设计方向
干净的私人记录本，不像校务ERP或焦虑营销工具。强调“记录事实”，不用夸张进步榜、排行榜、差生标签。
Material 3为基础，保留安卓返回、输入法、系统文件选择和系统分享体验，不仿iOS导航。
禁止拿竞品截图/图标直接临摹；结构源于本项目流程。

## 设计令牌（项目设计选择）
浅色：背景#F7F8FA，卡片#FFFFFF，文字#17242C，次级#5A6B75，主色#356A5A，描边#DCE3E0。
深色：背景#101817，卡片#1B2623，文字#E2ECE7，次级#B2C4BA，主色#9FD2BA。
错误信息使用可访问的主题error色并配图标/文字；变化不上红绿价值判断。
圆角：卡片20dp/输入12dp；页面边距20dp；卡片内16dp；间距8/12/16/24；主要触区≥48dp。
字体：系统中文；标题24sp、页面标题20sp、正文16sp、说明14sp；2倍缩放不能裁剪数据。
首版固定品牌色，不启用动态色以免跨机差异阻碍验收；深浅随系统，也可设置覆盖。

## 信息架构
底部导航3项：记录 / 趋势 / 设置。全局当前孩子切换在记录/趋势顶部。
“记一次成绩”固定为易触达主按钮；初次无孩子时转为“创建孩子档案”。
页面清单：欢迎隐私、孩子管理、记录首页、考试编辑、考试详情、趋势、报告预览、备份恢复、设置、升级。
每页都定义loading/empty/error/content；不能用转圈掩盖失败。

## 关键页面布局
记录页：孩子切换→最近记录摘要→历史筛选chips→按月分组的考试卡片→主录入按钮。
录入页：标题/日期/学期/类型→科目行（名称、得分/满分、状态）→添加科目→保存；
满分输入不能藏很深；每行错误就地提示；顶栏返回保留草稿/放弃的非破坏性选择。
趋势页：科目选择→原始分/得分率切换→图→明确口径→明细表；缺失状态不被点图隐藏。
设置：孩子与科目→备份/恢复/最近成功备份→专业版→隐私/帮助→版本→清除数据。
升级页：清楚列免费保留内容与解锁内容，真实价格/恢复购买/取消；无倒计时或虚构划线价。

## 完整性
保存反馈用Snackbar与无障碍播报；网络不可用不影响本地入口。
0记录、1记录、3记录（免费）、超过3的恢复、归档孩子均需截图验收。
删除需对话框明确数量，默认取消；事务失败不移除列表项。
图表旁必须有表格；颜色不能是唯一状态载体。TalkBack读出分数、满分、状态，不暴露调试ID。
数字输入键盘支持小数；焦点顺序清晰；edge-to-edge使用系统insets，导航栏和键盘不遮按钮。

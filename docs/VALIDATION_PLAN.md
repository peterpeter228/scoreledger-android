# 用户验证与冷启动（不自动对外发送）

第一组：20位确实记录过孩子成绩的成年家长。了解当前使用纸笔/表格/其他App的方法，询问不记录的原因。
可用性阶段：5位家长使用虚构样本或自己保留在手机上的资料，独立完成孩子→考试→趋势→PDF→备份。
不向dot上传真实孩子成绩。记录完成情况、卡点、主观信任和再次使用意愿；不采集无必要的个人身份。

定价验证：免费体验+¥18买断为假设。只有正式渠道真实付款才计收入；促销、测试订单、自己的购买分开。
不凭原iOS付费榜预测Android下载量。安卓中文渠道、购买习惯与分发资格必须重新验证。

建议冷启动渠道：小红书家长会整理教程、经管理员允许的微信家长群、小规模家庭教育内容合作。
这些是候选行动，不是本包对dot授权自动发帖/群发/购买流量。发布前需用户批准。

观察：首次完成记录、下一次考试继续录入、导出成功、付费意愿。首版无埋点SDK，采用自愿访谈和本地调试计数。
停止/调整：多数人不愿录入；报告没有再次使用价值；只能靠人工代录维持；真实交易未能建立。
先降低录入成本，不自动扩展OCR/AI；任何新增功能先做小验证。

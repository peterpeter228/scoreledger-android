# 首版中文文案
欢迎标题：把每一次成绩，记录清楚。
欢迎说明：无需注册。记录保存在这台设备上，请定期导出备份。
孩子昵称说明：可以使用昵称，不必填写真实姓名。
主按钮：记一次成绩
空记录：还没有记录。先记下最近的一次考试。
空趋势：至少记录一次有分数的成绩后，就能在这里查看。
一条数据：目前只有一次成绩，暂不展示变化趋势。
得分率提示：得分率只统一满分口径，不能消除试卷难度差异。
不完整汇总：仅汇总已录入分数的科目（{recorded}/{selected}科）。
不可比：两次考试的科目、满分或范围不同，暂不比较总分变化。
缺考：缺考（不按0分计算）
未录入：暂未录入
保存失败：未能保存。你的草稿仍在，请检查设备空间后重试。
导出提醒：文件可能包含孩子的记录。请只保存或分享给信任的人。
明文备份：这是未加密备份，请妥善保管。PDF报告不能用于恢复记录。
恢复确认：恢复将替换本机现有{oldCount}次考试，导入{newCount}次。是否继续？
格式不支持：无法读取这个备份版本。本机记录未被更改。
免费限制：免费版可保留3次考试。已有记录仍可查看、纠错、导出和备份。
购买标题：一次解锁，继续记录
渠道不可用：此版本暂未开通购买。本地记录和备份仍可使用。
内测标识：内测版 · 未开通付费
购买恢复：恢复购买
无购买记录：暂未找到此账号在当前渠道的购买记录，请确认购买账号与渠道。
退款/失去权益：当前未检测到专业版权益。已有记录保持可用；新增数量按免费规则计算。
清除说明：这会删除本机记录及内部恢复快照，不会删除你已经导出的文件。
卸载提醒：卸载可能删除本机记录。换机或卸载前，请先导出备份并核验恢复。
禁用文案：必提分、准确预测、学习能力分、标准分（无依据）、全国排名、永久不丢、100%通过审核、零合规风险。
